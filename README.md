# FluentX - Premium English Learning Platform

FluentX is a modern, full-stack web application designed for interactive English language learning, speaking practice, live classes, and resource access.

## Architecture

- **`backend/`**: Express.js REST API providing courses, live classes, resources, speaking club schedules, and authentication.
- **`frontend/`**: Vite + React 19 single-page web application featuring responsive dark UI, speech practice widgets, quiz engines, and interactive modules.

## Getting Started

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

## Features

- 📚 Comprehensive Course Catalog with lesson players
- 🗣️ Speech Practice Widget with speech synthesis & feedback
- 🎙️ Interactive Speaking Club session directory
- 📜 Certificate Generation for course completion
- 📝 Quiz Engine with score calculations and feedback
