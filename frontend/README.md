# FluentX Frontend Client

The frontend user interface for **FluentX - Premium English Learning Platform**, built using **Vite**, **React 19**, and **Lucide React Icons**.

## Tech Stack & Highlights

- ⚡ **Vite 8** for instant hot-module replacement (HMR) and fast build times
- ⚛️ **React 19** with Context API (`AuthContext`, `CourseContext`)
- 🎨 **Pure CSS** design tokens, glassmorphism, responsive grid layouts
- 🎙️ **Web Speech API** integration for speech evaluation and pronunciation synthesis
- 📜 **Canvas Confetti** & dynamic certificate generator modal
- 📊 **Oxlint** for fast, modern JavaScript code linting

## Available Scripts

- `npm run dev`: Launch the local development server on port 5173
- `npm run build`: Build production bundle into `/dist`
- `npm run lint`: Run Oxlint checks on source code
